## Technical data-flow inventory

- Static delivery currently uses GitHub Pages. GitHub states that visitors' IP
  addresses are logged and stored for security purposes.
- The app itself includes no analytics, advertising, profiling, third-party
  embeds or externally hosted webfonts.
- Language, theme, accessibility preferences and dismissal of the privacy
  notice are stored in local storage.
- WhatsApp, email, telephone, Google Maps and Google reviews are links only.
  Their services are contacted only after the visitor activates a link.
- The website contains a local email template that can be completed with child
  information. The website does not submit or store this template.
- Supplied photographs and shortened review excerpts are served locally. No
  Google content is embedded while the page is displayed.
